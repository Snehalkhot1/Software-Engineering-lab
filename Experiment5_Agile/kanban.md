## Kanban Principles
1. Visualize the workflow.
2. Limit work in progress (WIP).
3. Track tasks continuously.
4. Identify bottlenecks.
5. Improve the process continuously.

## Kanban Result
The Kanban board makes task status visible and supports
continuous workflow without requiring fixed-length sprints.
