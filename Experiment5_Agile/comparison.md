
# Comparison of Agile Development Methodologies

## Project
Student Management System

| Parameter | Scrum | Kanban | Extreme Programming (XP) |
|---|---|---|---|
| Development cycle | Fixed-length sprints | Continuous workflow | Iterative and frequent releases |
| Planning | Sprint planning | Continuous task planning | Iterative planning |
| Workflow | Product and sprint backlogs | Visual Kanban board | Coding and testing practices |
| Team size | Often medium to large | Any suitable team size | Small teams work well |
| Customer feedback | Sprint reviews | Continuous feedback | Frequent customer feedback |
| Flexibility | High | Very high | High |
| Meetings | Daily Scrum and sprint events | Meetings as needed | Frequent team communication |
| Testing | During development and sprint | Continuous as tasks progress | Test-driven development |
| Delivery | Working increment at sprint end | Whenever work is ready | Small, frequent releases |
| Best suited for | Projects needing sprint goals | Projects needing continuous flow | Projects emphasizing code quality |

## Observations

1. Scrum organizes work using sprints and defined responsibilities.
2. Kanban makes the workflow visible and helps identify delays.
3. XP emphasizes automated testing, code quality, and continuous feedback.

## Result

The Student Management System was used to demonstrate
Scrum planning, Kanban workflow management, and XP testing
practices. Each methodology offers a different way to organize
development and improve software quality.
