Agile Methodologies

Scrum

Scrum

  • Team works in short sprints.
  • Product backlog is prioritized.
  • Daily stand-up meetings track progress.
  • Example: login page, payment module, dashboard.
Kanban

Kanban

  • Work is visualized on a board.
  • Tasks move from To Do to Done.
  • Helps limit work in progress.
  • Example: design, coding, review, testing.
XP

Extreme Programming

  • Focus on coding and testing together.
  • Pair programming improves quality.
  • Continuous integration keeps the project stable.
  • Example: write tests, code, and refactor quickly.
