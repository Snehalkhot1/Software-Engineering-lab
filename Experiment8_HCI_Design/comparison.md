
# Experiment 8: Human-Computer Interaction Design

## Aim
To design and compare different HCI designs using a
Student Management System.

## HCI Designs
1. Menu-driven interface
2. Form-based interface
3. Dashboard-based interface

## Comparison Table

| Parameter | Menu-Driven | Form-Based | Dashboard-Based |
|---|---|---|---|
| Interaction | Text and numbered choices | Input fields and buttons | Summary cards, fields and buttons |
| Ease of learning | Easy for simple menus | Easy for users familiar with forms | Easy to navigate after brief guidance |
| Visual appearance | Basic text interface | Structured graphical form | Graphical overview with summary information |
| User feedback | Text messages in terminal | Dialog boxes and form results | Dialog boxes and summary updates |
| Navigation | Select menu numbers | Use fields and action buttons | Use dashboard controls |
| Error prevention | Depends on input validation | Labels and validation messages | Labels, action buttons and validation |
| Efficiency | Good for simple tasks | Good for data entry | Good for frequent operations and overview |
| Main advantage | Simple and lightweight | Clear data-entry process | Quick overview and access to operations |
| Main limitation | Less visual feedback | Can become crowded with many fields | May contain too much information |
| Suitable use | Basic command-line tools | Registration and data-entry applications | Administrative systems and dashboards |

## HCI Principles Applied

1. Consistency: Use clear and consistent labels.
2. Feedback: Display success and error messages.
3. Visibility: Make available actions easy to identify.
4. Error prevention: Validate student IDs, names and marks.
5. Simplicity: Keep the interface focused on common tasks.

## Observations
- The menu-driven interface is lightweight and simple.
- The form-based interface supports structured data entry.
- The dashboard-based interface provides an overview and
  convenient access to frequent operations.

## Result
Three HCI designs were implemented using Python and Tkinter
for the Student Management System. Their usability,
navigation, feedback and suitability were compared.
